# Nokia Network as Code -- removed from the catalog

This repository used to profile Nokia Network as Code. The company has a website of its own (networkascode.nokia.io), but every
API host the profile listed was a RapidAPI marketplace proxy (Nokia's Network as Code hub on RapidAPI (network-as-code.p-eu.rapidapi.com)), so what was catalogued was
the marketplace listing, not an API the company serves from its own host.

It was removed on 2026-09-23 as a catalog-hygiene decision by API Evangelist (roadmap#621). Nobody asked.
API Evangelist and APIs.io do not index RapidAPI listings.

The slug and the RapidAPI proxy hosts are on the delisting registry (api-search/network/_data/delisted.yml),
so harvests will not re-add this record. The company's own domain is not on the registry: if it publishes
an API from its own host, it can be catalogued from there. Questions: info@apis.io.
