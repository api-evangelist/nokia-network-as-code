# Nokia Network as Code

> Nokia's network-API exposure and aggregation platform, operated from Espoo, Finland. It aggregates many mobile operators' networks behind one contract, one credential and one set of SDKs, exposing CAMARA-standardised capabilities — identity and anti-fraud, device location and status, quality on demand, network slicing, congestion insights — to ordinary application developers. Two complete OpenAPI documents are published openly under Apache 2.0.

Generated by API Evangelist from the artifacts in this repository. Nokia publishes no llms.txt of its own (https://networkascode.nokia.io/llms.txt returns 404).

## What an agent needs to know first

- Production traffic is served through a white-labelled RapidAPI Enterprise Hub. The base URL is `https://network-as-code.p-eu.rapidapi.com`, not a Nokia-owned API hostname.
- Authentication is two layers: an `x-rapidapi-key` header at the gateway, and a CAMARA OAuth2 / OpenID Connect token for the network capability itself.
- The identifier rule decides most calls: with a two-legged (client-credentials) token the subscriber MUST be named in the request body; with a three-legged (subscriber-consented) token it MUST NOT be — the errors are `422 MISSING_IDENTIFIER` and `422 UNNECESSARY_IDENTIFIER`.
- There is no idempotency contract, no pagination contract and no rate-limit response headers. Retry with care and reconcile by listing.
- Errors are the CAMARA `ErrorInfo` envelope (`status`, `code`, `message`) — not RFC 9457 problem details.
- `SERVICE_NOT_APPLICABLE` (422) means the serving operator does not offer that capability for that subscriber. It is an aggregator boundary, not a transient failure.

## APIs

- [Nokia Network as Code Platform API](https://networkascode.nokia.io/docs): the single aggregated surface — 58 paths, 78 operations, base `https://network-as-code.p-eu.rapidapi.com`.
- [Nokia Network as Code CAMARA API](https://github.com/nokia/network-as-code-sdks): the CAMARA-conformant consolidated document — 52 paths, 70 operations, `x-camara-commonalities: 0.4.0`.
- [Digital Identity and Anti-Fraud](https://networkascode.nokia.io/products/digital-identity-and-anti-fraud): Number Verification, SIM Swap, Device Swap, Number Recycling, Call Forwarding Signal, KYC Match / Age Verification / Fill-in / Tenure.
- [Device Intelligence](https://networkascode.nokia.io/products/device-intelligence): Location Retrieval, Location Verification, Geofencing Subscriptions, Device Reachability and Roaming Status (retrieve and subscribe).
- [Programmable Connectivity](https://networkascode.nokia.io/products/programmable-connectivity): Quality on Demand, Network Slicing, Slice Device Attach.
- [Network Intelligence](https://networkascode.nokia.io/products/network-intelligence): Congestion Insights, Consent Info.
- [Authorization Server](https://networkascode.nokia.io/docs/getting-started): client-credentials issue, per-app JWKS, OIDC and OAuth well-known metadata (all behind the gateway key).
